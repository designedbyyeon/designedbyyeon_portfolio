# 디자인드바이연 포트폴리오

- 소개 문장 속 태그를 눌러 켜고 끄면서 작업을 필터링
  - 고른 태그로만 된 문장이 또렷해짐 (예: "한글레터링 작업으로 프로모션을 만듭니다.")
  - 태그에 마우스를 올리면 해당 작업만 남기고 흐려져 미리보기
- 작업을 클릭하면 상세 보기
- 필터된 작업을 PDF로 다운로드 (표지 1p + 프로젝트당 1p, A4 가로)
- `works/` 폴더에 작업 폴더를 넣으면 자동 반영

디자인 기준 시안: `0927_ref/site.png` (가로 2000px), 로고: `source/logo.svg`

## 실행 (내 컴퓨터에서 미리보기)

`serve.bat` 더블클릭, 또는:

```bash
python serve.py
```

브라우저에서 `http://localhost:8000` 이 열립니다. 켜둔 상태에서 `works/`나 `tags.txt`를 추가·수정하면 1~2초 안에 페이지에 반영됩니다.

> `index.html`을 직접 더블클릭해서 열면 동작하지 않습니다. 꼭 위 방법으로 여세요.

## 작업 추가하기

`works/` 안에 폴더를 하나 만들고 이미지와 설명 txt 파일을 넣습니다.
txt 파일 이름은 `info.txt` 또는 `폴더이름.txt` 모두 됩니다 (폴더 안에 txt가 하나뿐이면 이름 상관없음).

```
works/
  05_새작업/
    info.txt
    cover.jpg      ← 대표 이미지 (목록 타일·PDF에 크게 나옴)
    01.jpg
    02.jpg
```

`info.txt` 형식 (`works/_템플릿/info.txt` 복사해서 쓰면 편합니다):

```
프로젝트명: 대한의 가장 빛나는 여권
연도: 2023
클라이언트: 빙그레
태그: 한글레터링, 광고, TVC, 빙그레
유튜브: https://youtu.be/xxxxxxxxxxx
---
여기부터는 설명입니다.
빈 줄로 문단을 나눌 수 있습니다.
```

| 항목 | 설명 |
|---|---|
| 프로젝트명 | 없으면 폴더 이름을 사용 |
| 연도 · 클라이언트 | 비워두거나 줄을 지우면 표시 안 됨 |
| 태그 | 쉼표(`,`)로 구분. 붙여 쓴 `/`는 이름의 일부 (`방송/영화`는 태그 하나) |
| 유튜브 | 선택. 영상이 없으면 줄을 지우세요. 아래 참고 |
| 설명 (`---` 아래) | 목록에서 마우스를 올리면 앞부분이, 클릭하면 전체가 보임 |

고급 옵션 (필요할 때만):
- `순서: 1` — 숫자가 작을수록 앞에. 없으면 연도 최신순 → 폴더 이름순
- `대표이미지: 파일이름.jpg` — 대표 이미지 지정. 없으면 `cover.*` → 이름순 첫 이미지

기타:
- 이미지: jpg, png, webp, gif, svg. 이름순으로 정렬됩니다 (`01`, `02`, … 추천).
- 폴더 이름이 `_`로 시작하면 사이트에 안 나옵니다 (임시 저장용).
- 메모장에서 저장한 한글 텍스트(UTF-8/ANSI 모두) 인식합니다.

## 유튜브 영상 넣기

`info.txt`에 `유튜브:` 줄을 추가하고 유튜브 주소를 그대로 붙여넣습니다.

```
유튜브: https://youtu.be/xxxxxxxxxxx
```

- 주소 형식은 무엇이든 됩니다: `youtu.be/…`, `youtube.com/watch?v=…`, 쇼츠 `youtube.com/shorts/…` (공유 버튼 주소 그대로 OK)
- 영상이 여러 개면 `유튜브:` 줄을 여러 번 쓰거나 쉼표로 이어 쓰면 됩니다.
- 표시되는 곳
  - 목록: 타일 오른쪽 위에 ▶ 표시
  - 상세 보기: 이미지 위에 영상 플레이어 (쇼츠는 세로로)
  - PDF: "▶ 영상 보기" 링크 — PDF에서 클릭하면 유튜브로 이동
- 이미지 없이 영상만 넣으면 유튜브 썸네일이 대표 이미지로 쓰입니다. 다만 썸네일은 16:9라 3:4 타일에서 양옆이 잘리니, **대표 이미지(`cover.jpg`)는 따로 넣는 걸 추천**합니다.
- 주소를 인식하지 못하면 `serve.py` 창에 경고가 뜹니다.

## 이미지 사이즈

| 용도 | 권장 | 비고 |
|---|---|---|
| 대표 이미지 (`cover.*`) | **1200 × 1600px (3:4 세로)**, JPG/WebP, 500KB 이하 | 목록 타일이 3:4라서 다른 비율은 가운데 기준으로 잘림. 레터링이 잘리지 않게 3:4로 따로 크롭해서 넣는 걸 추천 |
| 상세 이미지 | 가로 2000px 안팎, JPG 품질 80 전후, 1MB 이하 | 비율 자유. 상세 보기에서 가로폭에 맞춰 세로로 나열 |

### 이미지 자동으로 줄이기

작업을 추가한 뒤 `optimize.bat`을 더블클릭하면 (또는 `python optimize_images.py`) `works/` 안의 이미지를 웹용으로 줄여줍니다.

- 가로 2000px 넘으면 2000px로 축소, PNG·JPG → WebP 변환 (투명 배경 유지)
- **원본 파일은 변환 후 삭제**되니, 원본은 다른 곳에 따로 보관하세요
- 이미 줄인 파일은 건너뛰므로 여러 번 실행해도 됩니다
- 2MB 넘는 이미지가 있으면 `serve.py` 창에 경고가 뜹니다
- 필요: `pip install pillow` (한 번만)

## 태그 (`tags.txt`)

태그는 두 종류로 나뉘고, 필터 화면에서 각각 한 줄씩 표시됩니다.

| 종류 | 표시 | 예 |
|---|---|---|
| **작업 종류** | 색 버튼 (태그 뒤에 `#색상`) | 한글레터링, 영문레터링, 포스터, 모션그래픽, 3D |
| **장르** | 회색 버튼 | 광고, 방송/영화, 엔터테인먼트, 프로모션, … |

```
[작업 종류]
한글레터링 #edc92f = 레터링, 영문레터링 #5ece3e, 포스터 #f49ac1, 모션그래픽 #4960ea, 3D #ea522f

[장르]
광고, 방송/영화 = 방송, 엔터테인먼트, 웹툰, 프로모션, 행사, F&B, CI, 패션, 게임
```

- **별칭**: `=` 뒤에 적은 이름으로 txt에 써도 앞의 이름으로 표시됩니다. 위 예시에선 txt에 `레터링`이라고 써도 사이트에는 `한글레터링`으로 나옵니다.

- `tags.txt`에 없는 새 태그는 자동으로 **장르**(회색)에 들어갑니다. 새 작업 종류를 만들 땐 `[작업 종류]` 줄에 색과 함께 추가하세요.
- 작업이 하나도 없는 태그는 화면에 나오지 않습니다.

필터 규칙: **같은 줄 안에서는 "하나라도", 두 줄 사이는 "모두"**.
- 한글레터링 + 3D → 둘 중 하나라도 해당하는 작업
- 한글레터링 + 광고 → 한글레터링이면서 광고인 작업

## 활동 추가하기 (ACTIVITY)

워크숍·강의·아트프로젝트·대외활동은 `activities/` 폴더에 작업과 **똑같은 방식**(폴더 + txt + 이미지)으로 넣습니다. 상단 ACTIVITY 메뉴에 나옵니다.

```
activities/
  2025 레터링 워크숍/
    2025 레터링 워크숍.txt   ← 형식은 작업과 동일 (프로젝트명·연도·클라이언트·태그·유튜브·설명)
    01.jpg
    02.jpg ...
```

- 한 활동이 한 줄로 보입니다: 왼쪽에 날짜·태그, 오른쪽에 제목·주최·설명, 그 아래 사진 여러 장이 가로로.
- 설명은 3줄까지 보이고 "더 보기"로 펼침. 펼치면 사진도 줄바꿈되어 전부 보임. 사진을 누르면 크게 보기.
- 연도는 `2025.07`처럼 월까지 써도 됩니다 (최신순 정렬).
- 태그는 `tags.txt`의 `[활동]` 줄에 정의 (워크숍, 강의, 아트프로젝트, 대외활동). 작업 태그와 섞이지 않습니다.
- 빈 양식: `activities/_템플릿/info.txt`

## 연락처 (`contact.txt`)

상단 CONTACT를 누르면 열리는 창의 문장이 이 파일로 만들어집니다. 값을 비워두면 그 부분은 문장에서 빠집니다.

```
이메일: name@example.com
전화: 010-0000-0000
카카오톡: kakao_id
인스타그램: @instagram_id
```

- 이메일은 누르면 메일 쓰기, 전화는 전화 걸기, 인스타그램은 계정으로 이동, 카카오톡 아이디는 누르면 복사됩니다.
- '로/으로' 같은 조사는 값에 맞춰 자동으로 붙습니다.

## 로고 색

태그에서 작업 종류(색 태그)를 고르면 로고의 [바이]가 그 색으로 바뀝니다. 여러 개를 고르면 가장 마지막에 고른 색.

## 필터 링크 공유

태그를 선택하면 주소가 `…/#tags=한글레터링,TVC` 처럼 바뀝니다. 이 주소를 그대로 보내면 받는 사람도 같은 필터 상태로 보게 됩니다.

## 온라인 배포 (GitHub Pages)

`main`에 push하면 `.github/workflows/deploy.yml`이 `works.json`을 새로 만들어 자동 배포합니다.
처음 한 번만: GitHub 저장소 → Settings → Pages → Source를 **GitHub Actions**로 설정.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `build.py` | `works/` + `tags.txt` → `works.json` 생성 |
| `serve.py` | 로컬 서버 + 변경 감지 시 자동 빌드 |
| `optimize_images.py` | 이미지 웹용 축소·WebP 변환 |
| `index.html` / `style.css` | 화면 |
| `app.js` | 문장형 태그 필터, 작업 목록, 상세 보기 |
| `pdf.js` | PDF 생성 (각 페이지 레이아웃은 `drawWorkPage`) |
