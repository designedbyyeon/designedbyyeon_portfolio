# designedbyyeon 포트폴리오 (프로토타입)

기능 확인용 프로토타입입니다. 디자인은 최소한으로만 잡혀 있습니다.

- 태그를 눌러 켜고 끄면서 작업을 필터링 (AND / OR 전환)
- 필터된 작업을 PDF로 다운로드 (표지 1p + 프로젝트당 1p, A4 가로)
- `works/` 폴더에 작업 폴더를 넣으면 자동 반영

## 실행 (내 컴퓨터에서 미리보기)

`serve.bat` 더블클릭, 또는:

```bash
python serve.py
```

브라우저에서 `http://localhost:8000` 이 열립니다. 켜둔 상태에서 `works/` 안의 파일을 추가·수정하면 1~2초 안에 페이지에 반영됩니다.

> `index.html`을 직접 더블클릭해서 열면 동작하지 않습니다. 꼭 위 방법으로 여세요.

## 작업 추가하기

`works/` 안에 폴더를 하나 만들고 이미지와 `info.txt`를 넣습니다.

```
works/
  05_새작업/
    info.txt
    cover.jpg      ← 대표 이미지 (카드·PDF에 크게 나옴)
    01.jpg
    02.jpg
```

`info.txt` 형식 (`works/_템플릿/info.txt` 복사해서 쓰면 편합니다):

```
제목: 대한의 가장 빛나는 여권
태그: 레터링, 광고, TVC, 빙그레
연도: 2023
클라이언트: 빙그레
역할: 타이틀 레터링
---
여기부터는 설명 본문입니다.
빈 줄로 문단을 나눌 수 있습니다.
```

| 항목 | 설명 |
|---|---|
| 제목 | 없으면 폴더 이름을 사용 |
| 태그 | 쉼표(`,`) 또는 슬래시(`/`)로 구분 |
| 연도 · 클라이언트 · 역할 | 선택. 비워두면 표시 안 됨 |
| 순서 | 선택. 숫자가 작을수록 앞에. 없으면 연도 최신순 → 폴더 이름순 |
| 대표이미지 | 선택. 파일 이름을 적으면 그 이미지가 대표. 없으면 `cover.*` → 이름순 첫 이미지 |
| 그 외 `키: 값` | 상세 보기에 그대로 표시 (예: `매체: 유튜브`) |

- 이미지: jpg, png, webp, gif, svg. 이름순으로 정렬됩니다 (`01`, `02`, … 추천).
- 폴더 이름이 `_`로 시작하면 사이트에 안 나옵니다 (임시 저장용).
- 메모장에서 저장한 한글 텍스트(UTF-8/ANSI 모두) 인식합니다.

## 태그 그룹 (`tags.txt`)

필터 화면에서 태그를 묶어 보여줄 그룹과 순서를 정합니다. 여기에 없는 태그는 자동으로 `기타` 그룹에 들어갑니다.

```
[분야]
레터링

[형태]
광고, TVC, 워크숍
```

## 필터 링크 공유

태그를 선택하면 주소가 `…/#tags=레터링,TVC` 처럼 바뀝니다. 이 주소를 그대로 보내면 받는 사람도 같은 필터 상태로 보게 됩니다.

## 온라인 배포 (GitHub Pages)

`main`에 push하면 `.github/workflows/deploy.yml`이 `works.json`을 새로 만들어 자동 배포합니다.
처음 한 번만: GitHub 저장소 → Settings → Pages → Source를 **GitHub Actions**로 설정.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `build.py` | `works/` + `tags.txt` → `works.json` 생성 |
| `serve.py` | 로컬 서버 + 변경 감지 시 자동 빌드 |
| `index.html` / `style.css` | 화면 |
| `app.js` | 태그 필터, 카드, 상세 보기 |
| `pdf.js` | PDF 생성 (각 페이지 레이아웃은 `drawWorkPage`) |
